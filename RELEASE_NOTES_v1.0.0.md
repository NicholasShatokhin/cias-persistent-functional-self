# Replication Package v1.0.0 — A Causal Theory of Persistent Functional Self in Embodied Artificial Agents

Frozen replication materials for:

**A Causal Theory of Persistent Functional Self in Embodied Artificial Agents**

**Author:** Mykola Shatokhin  
**ORCID:** 0000-0003-0028-6208

This release contains the frozen code, scientific protocols, raw diagnostic and confirmatory data, analysis scripts, and provenance records required to reproduce the principal v7.0 results reported in **"A Causal Theory of Persistent Functional Self in Embodied Artificial Agents"**.

## Primary confirmatory result

The frozen v7.0-r1 held-out experiment tests persistent functional identity under adversarial morphology and appearance change.

The release supports reproduction of:

- persistent identity continuity analysis;
- old-appearance lure rejection;
- paired-seed confidence intervals;
- four-embodiment results;
- confirmatory PASS under the preregistered criteria.

## Reproduction

```bash
python analysis/analyze_v70r1.py \

  --outdir reproduced_analysis
```
